# 数组和指针

```cpp
int array1[4] = {9, 8, 7, 6};
```

![[指针示意图.png]]

**我们是可以访问到负index的指针并且修改此处的数据的（越界修改）**

```cpp
#include<iostream>
using namespace std;
int main()
{
    int num_array[5];

    for(int idx = -1; idx < 5; idx++){
        num_array[idx] = idx*idx;
    }

    for(int idx = -1; idx < 5; idx++){
        cout << "num_array[" << idx << "] = " << num_array[idx] << endl;
    }

    return 0;
}
```
