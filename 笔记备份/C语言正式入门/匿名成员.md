# 匿名成员

## 2026年7月24日

```cpp
#include <iostream>
#include <cstdint>
using namespace std;

enum datatype {TYPE_INT8=1, TYPE_INT16=2, TYPE_INT32=4, TYPE_INT64=8};

struct Point{
    enum datatype type;
    union{
        int8_t data8[3];
        int16_t data16[3];
        int32_t data32[3];
        int64_t data64[3];
    };
};

size_t datawidth(struct Point pt){
    return size_t(pt.type)*3;
}

int64_t l1norm(struct Point pt)
{
    int64_t result = 0;
    switch(pt.type)
    {
        case(TYPE_INT8):
            result = abs(pt.data8[0]) + abs(pt.data8[1]) + abs(pt.data8[2]);
            break;
        case(TYPE_INT16):
            result = abs(pt.data16[0]) + abs(pt.data16[1]) + abs(pt.data16[2]);
            break;
        case(TYPE_INT32):
            result = abs(pt.data32[0]) + abs(pt.data32[1]) + abs(pt.data32[2]);
            break;
        case(TYPE_INT64):
            result = abs(pt.data64[0]) + abs(pt.data64[1]) + abs(pt.data64[2]);
            break;
    }
    return result;
}
int main()
{
    //声明与初始化
    struct Point point1 = {.type=TYPE_INT8, .data8={-2, 3, 4}};
    struct Point point2 = {.type=TYPE_INT32, .data32={1, -2, 3}};

    cout << "Data width = " << datawidth(point1) << endl;
    cout << "Data width = " << datawidth(point2) << endl;

    cout << "L1 norm = " << l1norm(point1) << endl;
    cout << "L1 norm = " << l1norm(point2) << endl;

    return 0;
}
```

注意看以上代码，其中有个片段：

```cpp
struct Point{
    enum datatype type;

    union{
        std::int8_t data8[3];
        std::int16_t data16[3];
        std::int32_t data32[3];
        std::int64_t data64[3];
    };
};
```

其中的`union`居然没有名字！

形如：

```cpp
struct Point
{
    int type;

    union
    {
        int x;
        double y;
    };
};
```

编译器会把它理解成：

```cpp
struct Point
{
    int type;

    // 直接把成员展开
    int x;
    double y;
};
```

但是注意：

它不是普通的两个变量！

实际上仍然共享内存：

```
Point

+------+
|type  |
+------+
| x/y  |
+------+
```

所以你可以直接：

```
Point p;

p.x = 10;
```

而不能：

```
p.union.x
```

因为它根本没有名字。而正常情况下我们会选择给union命一个名，但实际上不命名也可以通过编译，且在这种情况下可以减少访问的层级。

同样的情况其实也可发生在`struct`和`enum`中，名字的作用在于决定是否创建一个**可复用的类型**，就算不命名也会开辟对应的内存空间。
